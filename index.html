图源设置

试行版内置示例图库开箱即用；如需联网真实检索，可填入 Pexels 免费 API Key
申请方式：访问 pexels.com/api 注册账号 → 申请 API Key → 复制填入。
Key 仅保存在你本机浏览器，不会上传到任何服务器。免费额度每月 200 次请求。

云端设置（TA境共享）

填入 Supabase 项目的 URL 和公开 API Key，即可启用共享广场。步骤见《云端配置指引》
去哪找：项目里点顶部 Connect，或左侧 Settings → API Keys（新版界面没有单独的 "API" 页面）。
复制 publishable key（sb_publishable_...）；旧版 anon / eyJ... 的 key 也能用。不要复制 secret / service_role 密钥。
这两项只保存在你本机浏览器，公开密钥设计上可暴露，真正的访问控制由数据表的 RLS 规则管理。
